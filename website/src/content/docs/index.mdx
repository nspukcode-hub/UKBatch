## What it is

UKBatch is a NuGet package family that orchestrates jobs and batches across one
service or many, with minimal code. You write a job once and decide later where
its state lives (in-memory or a database) and how services talk to each other
(in-process, HTTP, or RabbitMQ) — the job code does not change. Run it embedded
in your app with a built-in dashboard, or as a standalone server with worker
microservices.

<CardGrid stagger>
	<Card title="One-line integration" icon="rocket">

		Storage: InMemory / PostgreSQL / SQLite (EF Core). Transport: in-process /
		HTTP / RabbitMQ.

	<Card title="Real workflow patterns" icon="approve-check">
		Sequential, parallel fan-out/fan-in, manual approval gates, and cross-service
		steps via `.OnService("...")`.
	</Card>
	<Card title="Data-parallel jobs" icon="random">
		"Fetch a set, process on N workers" as a first-class primitive —
		`IPartitionedJob<TItem>`.
	</Card>

		A Blazor Server UI for monitoring, triggering, approvals, and a visual batch
